# Stock-Market-Simulator
A project acting as a Stock Market Simulator, able to buy and sell stocks with live stock market data.

Steps to obtain API key:
    1. Go to Financial Modelling Prep (https://site.financialmodelingprep.com)
    2. Create an account and choose the free plan
    3. An API key will be available on your dashboard (https://site.financialmodelingprep.com/developer/docs/dashboard)
        - Do NOT share this key with anyone

Note: The free plan has a limit of 250 calls/day, so use it wisely. Otherwise, you can also pay for a premium subscription for more calls. 

Have fun with the simulator.
